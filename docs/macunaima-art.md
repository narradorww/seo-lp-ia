# Macunaíma art direction

Generated with the built-in image generation tool. Cover: an original artistic tribute to Grande Otelo. Source PNGs remain in Codex generated_images; optimized WebP deliverables are in public/arcade/macunaima/assets.

- macunaima-otelo.webp — cover, 1672 × 941.
- forest-clearing.webp — nine-slice playable environment, 1774 × 887.
- characters.webp — transparent sprite atlas, 1536 × 1024; lossless WebP preserves alpha.

The game renderer uses the atlas for ants, leaves and four literary characters. Desktop uses 24 × 12 cells; phone uses 14 × 16. Collision boundaries match the thin line at the clearing edge. The responsive layout is selected at the start of each run; rotation pauses the current game instead of changing its rules mid-run.

## Final generation prompts

### Environment
Use case: stylized-concept. Asset type: actual playable top-down pixel-art background for a Brazilian Amazon snake game, 2:1 landscape. Create a richly detailed late SNES / 32-bit Jaguar era Amazon rainforest clearing. Strict overhead camera, NO horizon, NO perspective landscape. A wide rectangular open walkable floor of warm muted ochre earth takes the central 86% width and 78% height, very subtle earth texture and scattered tiny fallen leaves only, consistent low contrast so tiny animated ants will stand out. Dense lush rainforest frames ALL FOUR edges: layered dark teal foliage, individual fern fronds with golden green highlights, gnarled roots, mossy trunks, bromeliads and small magenta flowers. The inner edge of vegetation must outline a clear straight rectangular playable area, about x7%-93%, y11%-89%; absolutely no large objects intrude into it. Rich carefully placed pixel clusters, dithered shadow transitions, 32+ colors, sun patches, handcrafted premium 1990s game background with volumetric shading. NOT crude 8bit tile checkerboard, not flat vector, no blur. No text, title, branding, grid, UI, characters, ants or food. Entire asset is environment art, landscape 2:1.
